课堂实录回放笔记 · Safari 版  v0.9.4 使用说明
==============================================

适用：Apple Silicon（M1/M2/M3/M4）+ macOS 15 或更新 + Safari 17 或更新。
Intel Mac 和 macOS 14 及以下不能运行。

界面与图标（v0.9.4）
--------------------
- 侧栏统一为北大红主题：红色渐变标题栏、北大红按钮 / 进度条 / 链接，
  阅读区改为暖白底色。
- 新图标为「笔记 + 回放」图形，Safari 工具栏图标和 Mac App 图标同步更新；
  课程列表的「学习状态」列也使用北大红强调色。


一、安装：双击「一键安装.command」就行
--------------------------------------
1. 解压 zip。
2. 双击「一键安装.command」。
   如果 macOS 提示“无法验证开发者”：右键 →「打开」→ 再点「打开」。
3. 安装脚本会自动完成：
   - 把 App 装到「个人/应用程序」；
   - 修复签名（之后运行不需要再重签）；
   - 注册 Safari 扩展；
   - 打开 App 和 Safari。
4. Safari 如果提示「允许未签名的扩展」：点「允许」/输入 Touch ID。
   这是 Apple 对未签名扩展的安全要求，只需按提示确认一次。
5. 回到教学网，刷新页面即可。

不需要手动把 App 拖进「应用程序」；
不需要手动打开 Safari 的开发者菜单；
不需要手动去扩展列表里加载或勾选本扩展。
升级安装也用同一个「一键安装.command」：脚本会自动清理旧版扩展注册和旧 App 副本。
如果 Safari 扩展列表里仍然有两个同名条目，再双击「清理旧版残留.command」，
然后完全退出 Safari 再打开一次。


二、以后重新打开 Safari
------------------------
只要 Safari 完全退出过，Apple 就会清掉「允许未签名的扩展」，
扩展可能从列表里消失。这时：

1. 再双击一次「一键安装.command」即可。
   它会自动重新安装、修复签名、注册扩展并打开 Safari，
   不需要手动拖文件、找菜单或改设置。
2. Safari 若再次要求「允许未签名的扩展」，按提示确认一次。
3. 刷新教学网页面。

也可以双击「修复扩展检测.command」做快速修复，效果一样。
整个过程就是“双击一次 + 按提示确认”，没有其他手动步骤。

想永久免掉这一步，只能用 Apple Developer 账号（99 美元/年）签名并公证；
当前包是 ad-hoc 签名，没有账号就绕不过 Safari 的限制。


三、课程列表和回放页
--------------------
1. 打开教学网「课堂实录」课程列表。
   表格最右边会出现「学习状态」列，说明扩展在工作。
2. 点「观看」进入回放页，右侧会出现面板。
3. 如果列表没有状态列、回放页也没有面板：
   先双击「修复扩展检测.command」，再看
   Safari → 设置 → 扩展 → 课堂实录回放笔记 → 网站访问，允许：
   - course.pku.edu.cn
   - onlineroomse.pku.edu.cn
   回放页的播放器在 onlineroomse 的 iframe 里，必须允许它。
4. 设置完后刷新页面。


四、基本使用
------------
- 记笔记：播放到想记的位置，按 Ctrl+B 或点「在此打点」。
- 面板位置：拖动顶部标题栏移动；拖四边或四角调整大小；
  双击标题栏，或点齿轮底部「重置面板位置」，恢复默认。
- 一键转写：字幕 → 一键转写本节。
- 资料：上传 PPT / PDF / Word，按课程和章节独立保存。
- 讲义：字幕 + 资料生成，可全屏预览、下载 PDF。
- 下载视频：进度条下方，可暂停/继续/取消。
- AI 讲解：面板右上角齿轮里填自己的 API Key。
  点「获取模型」可以读取服务商当前可用的模型；
  DeepSeek 现在用 deepseek-flash / deepseek-v4-pro，旧的 deepseek-chat 已停用。
  Key 不在压缩包里；不填也能用本地字幕、资料和 PDF。
- App 关掉窗口不会退出，会留在菜单栏；要退出用菜单栏「退出」。


五、常见问题
------------
Q：设置 → 扩展里没有「课堂实录回放笔记」？
A：先双击「修复扩展检测.command」，等它重新注册完；
   若 Safari 要求「允许未签名的扩展」，按提示确认一次。
   仍然没有：退出 App 再打开一次，然后再运行一次脚本。

Q：升级后 Safari 扩展列表里出现两个同名插件？
A：新版安装脚本会自动清理旧版；若仍有两个，双击「清理旧版残留.command」，
   然后完全退出 Safari 再打开一次。不要同时保留两个版本的 App。

Q：双击「一键安装.command」没有反应？
A：在终端里看有没有报错；或右键 → 打开。
   也可以先把 App 拖进「应用程序」，再运行「修复扩展检测.command」。

Q：课程列表没有「学习状态」列？
A：扩展没启用，或没有网站访问权限。
   双击「修复扩展检测.command」后，在
   Safari → 设置 → 扩展 → 课堂实录回放笔记 → 网站访问里允许
   course.pku.edu.cn。

Q：回放页没有右侧面板？
A：播放器在 onlineroomse.pku.edu.cn 的 iframe 里，
   网站访问里必须同时允许 onlineroomse.pku.edu.cn，然后刷新。

Q：提示连不上本地服务？
A：看菜单栏有没有「笔记 ●」；没有就打开一次 App。
   再到 系统设置 → 隐私与安全性 → 本地网络，
   允许 Safari 和本 App。

Q：一键转写提示 CDN 拒绝？
A：正常。Safari 会自动改用播放页面的登录态下载，
   然后在本机转写，等它完成即可。

Q：转写很慢？
A：2 小时课程大约下载 3-5 分钟、转写 20-40 分钟（视芯片而定）。
   转写在后台跑，页面可以切走，但不要关 App 和 Safari。

Q：想永久免掉每次允许未签名扩展？
A：需要 Apple Developer 账号（99 美元/年）做签名和公证。
   当前是 ad-hoc 签名，没有账号就绕不过 Safari 的限制。


六、卸载
--------
1. 先双击「清理旧版残留.command」，把旧版 App 和旧注册移到废纸篓/清掉；
2. Safari → 设置 → 扩展，取消勾选本扩展；
3. 删除「应用程序」里的 App；
4. 删除 ~/Library/Application Support/PRN；
5. 删除 ~/Downloads 里已下载的视频；
6. 清空废纸篓里的旧版本。
