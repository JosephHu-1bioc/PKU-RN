课堂实录回放笔记 v0.9.4 更新说明
==============================

一、侧栏（右侧面板）
1. 新增拖动：按住顶部标题栏，可以把面板移到任意位置，不再固定挡住播放器。
2. 新增缩放：拖动面板的四条边或四个角，可以拉长、拉宽、缩小。
3. 位置和大小会保存在本机 chrome.storage.local，刷新页面后恢复。
4. 双击标题栏可恢复默认位置；齿轮设置底部也有「重置面板位置」。
5. 自适应：
   - 面板变窄时，字号、内边距、按钮和栏目会自动收紧；
   - 面板变宽时，阅读区、讲义和笔记字号会放大；
   - 面板高度较小时自动隐藏次要标签、收紧间距；
   - 停靠在右侧时，宽屏会把网页正文让出来，避免压住视频。

二、AI 设置（齿轮）重塑
1. 产品已统一为「本地音频转文字」，因此：
   - 删除「允许把当前画面发给 AI」开关；
   - 删除「检测画面」按钮；
   - 删除视觉模型 / 画面讲解 / 扫片讲义等说明；
   - AI 只接收文字（笔记、字幕、资料页）。
2. 设置界面只保留：服务商、接入地址、API Key、模型、测试连接、保存。
3. 新增「获取模型」：读取服务商 /models 的当前模型并以胶囊按钮列出，点一下即可切换。
4. 新增「测试连接」的真实性验证：发送 1 token 的最小对话请求，确认模型名真的能调用。
5. 新增「高级：思考模式」开关（DeepSeek V4 / 智谱 GLM），默认关闭以加快随堂响应。
6. 视觉相关说明和按钮不再出现；原有笔记、字幕、资料、讲义功能不受影响。

三、服务商模型识别修复（重点）
1. 修复 DeepSeek 只显示 deepseek-chat 的问题：预设模型已更新为
   deepseek-flash（V4.1 Flash）与 deepseek-v4-pro（V4 Pro）。
2. DeepSeek 于 2026-07-24 停用 deepseek-chat / deepseek-reasoner；
   老配置打开设置时会自动迁移到 deepseek-flash。
3. /models 接口返回不全（例如中转服务只返回旧别名）时：
   - 可以继续手填任意模型名；
   - 「测试连接」会用最小请求验证该模型是否真的可用；
   - 模型输入框保留自由输入，不再被旧列表强行覆盖。
4. 兼容更多 /models 地址：<base>/models、<base>/v1/models、去掉版本号的 <base>/models 会依次尝试。

四、版本与打包
- manifest version 与 Mac Info.plist 版本均更新为 0.9.4。
- Windows 便携包解压后即可加载；Mac 包解压后运行「一键安装.command」即可（脚本会自动重签）。
- 该版本仅把「AI 画面 / 视觉模型」相关入口去掉，不删除你的历史笔记、字幕与讲义。

五、升级/卸载残留修复（v0.9.4）
1. Windows 扩展改为固定扩展 ID，以后从新目录更新不会因为路径变化产生新 ID。
2. 新版打开教学网时自动检测同名旧版扩展，浏览器弹一次「移除」确认框。
3. 齿轮新增「清理旧版残留」按钮，可一键再清理（浏览器仍会要求确认一次）。
4. 根目录新增「清理旧版残留.bat」，用于删除旧版文件夹。
5. Safari 版安装/修复脚本会清理重复的扩展注册和旧 App 副本，并新增
   「清理旧版残留.command」。

六、界面与图标（v0.9.4）
1. 侧栏统一为北大红主题：红色渐变标题栏、北大红按钮 / 进度条 / 链接，
   阅读区改为暖白底色。
2. 新版图标采用「笔记 + 回放」图形，16/32/48/128 像素同步更新。
3. 课程列表「学习状态」列使用北大红强调色。
