# 课堂实录回放笔记 · 便携版 v0.9.4

这是一个 **Windows 10/11 64 位** 的便携包：**不需要安装 Python、Node、FFmpeg，也不需要下载模型**。
压缩包里已经包含：

- Edge 扩展；
- 可直接运行的 Python 运行时；
- 语音转写依赖；
- 基础中文模型（`base`，约 0.15GB）；
- 本地 PDF/Word 解析依赖。

> 只支持 Windows x64 + Microsoft Edge。
> AI 讲解 / 讲义还需要你自己在扩展里填一个 LLM API Key（DeepSeek / GLM / 通义 / 豆包 / Kimi 任选）。

## 一、安装

### 1. 解压

把整个 zip 解压到一个**纯英文、无空格的路径**，例如：

```
D:\PRN
```

不要放在含中文/空格的路径里。**必须先解压**；不要直接选择 zip 文件，也不要在压缩软件的虚拟目录里点。

### 2. 安装 Edge 扩展

1. 打开 Edge，地址栏输入 `edge://extensions`
2. 打开左下角 **开发人员模式**
3. 点 **加载解压缩的扩展**
4. 选择解压后的 **`PRN-Portable-v0.9.4` 根目录**（这一层里面直接有 `manifest.json`；不是 runtime/service 子目录，也不是 zip 文件）
5. 扩展出现后，如果提示读取 Cookie 权限，请允许
   （这是为了 HLS 视频的 AES key，只在本机使用）

### 3. 启动本地服务

双击：

```
启动服务.bat
```

会弹出一个黑色命令行窗口，看到类似：

```
PRN whisper service on http://127.0.0.1:8765 ...
```

就说明服务已启动。**这个窗口在用时不要关**；关闭窗口就停止转写服务。

> 第一次启动如果 Windows 防火墙询问，请允许“专用网络”。服务只监听 `127.0.0.1`，不会对局域网开放。
>
> 如果提示端口 8765 被占用：先关掉旧的 `启动服务.bat` 窗口，再重新打开。

### 4. 刷新教学网

回到北大教学网，**刷新播放页**。
每次重新加载扩展或重启服务后，都需要刷新一次播放页，否则页面里的旧脚本会报 `Extension context invalidated`。

## 二、使用

### 记笔记 / 打点

- 打开视频后，右侧会出现面板；
- 播放到想记录的位置，按 `Ctrl+B` 或点 **在此打点**；
- 点笔记左侧时间戳会跳回视频。

### 面板挡住视频 / 位置不合适（v0.9.4 新增）

- 按住**顶部标题栏**拖动，可以把面板移到不挡视频的位置；
- 拖动面板的**左/右/下边缘或四角**，可以拉长、拉宽、缩小；
- 双击标题栏，或点齿轮 → 底部「重置面板位置」，恢复默认；
- 位置和大小会保存在本机浏览器里，下次打开同一页面还在；
- 面板停靠在右侧时，宽屏会主动给正文让出空间；小屏则保持浮动，由你自己拖开。

### 一键转写（推荐）

1. 打开面板顶部 **字幕**
2. 点 **一键转写本节**
3. 等它显示“正在下载音频…” → “正在转写音频…” → 字幕出现

本便携包用 CPU 基础模型：

- 不需要下载视频；
- 不需要选文件；
- 音频只在本机处理，不上传；
- 2 小时课程在普通 CPU 上大约需要几十分钟，请耐心等；
- 如果 HLS 地址被 CDN 拒绝，仍可用 **转写本机视频** 兜底。

### 转写本机视频

1. 把音视频文件放进 `media` 文件夹；
2. 字幕 → **转写本机视频**；
3. 选择文件 → **转写选中的视频**。

服务只读取 `media` 目录里的文件，不能选其他路径。

### 生成详细讲义 / 下载 PDF

1. 面板顶部 **资料**：上传 PPT/PDF/Word（按课程/节独立保存）；
2. **字幕** → 生成讲义（字幕 + 资料）；
3. 讲义底部固定有 **全屏预览 / 下载 PDF**。

### AI 讲解（v0.9.4 重新设计）

面板右上角齿轮：

1. **服务商**：DeepSeek / Kimi / 通义 / 豆包 / 智谱 GLM；
2. **接入地址**：一般不用改；用中转/自建服务时填到 `/v1` 为止；
3. **API Key**：只保存在本机；
4. **模型**：
   - 点 **获取模型**，会读取服务商 `/models` 返回的当前模型；
   - DeepSeek 现在是 `deepseek-flash`、`deepseek-v4-pro`；旧的 `deepseek-chat` 已停用；
   - 列表不全时可以直接手填模型名；
   - 点 **测试连接**，扩展会发一条 1 token 的最小请求，确认这个模型真的能调用；
5. **保存**。

没有 Key 也可以使用本地字幕、打点、资料解析和讲义排版。

### 下载视频

进度条下方有 **下载视频**；下载中可暂停/继续/取消。
如果某个回放的 HLS key 仍失败，优先使用 **一键转写**，或把错误发给我。

## 三、常见问题

### 为什么 Edge 里会出现两个「课堂实录回放笔记」？

通常是旧版目录和旧扩展没有移除，又加载了新版。新版首次打开教学网时会自动检测并弹窗请求移除旧版；如果没弹或点了取消，打开面板右上角齿轮 →「清理旧版残留」再试一次。移完请刷新页面；仍残留时关闭 Edge，双击根目录的 `清理旧版残留.bat` 删除旧文件夹。

### 面板挡住了视频 / 跑到屏幕外

拖动标题栏移开；双击标题栏，或点齿轮 → 「重置面板位置」恢复默认。面板位置/大小存在本机，换浏览器窗口大小时会自动拉回可见区域。

### AI 设置里模型只有 `deepseek-chat` / 测试连接报 400

请使用 v0.9.4，并点一次「获取模型」。DeepSeek 官方已下线 `deepseek-chat`，应选 `deepseek-flash` 或 `deepseek-v4-pro`。如果是中转服务且 `/models` 不返回新模型，直接手填模型名，再点「测试连接」验证。

### 扩展报 `Extension context invalidated`

扩展重新加载后，旧页面必须刷新。按 `Ctrl+R`。

### 面板提示连不上本地服务

1. 确认 `启动服务.bat` 黑窗口还在；
2. 打开 `http://127.0.0.1:8765/health`，应看到 JSON；
3. 关掉占用 8765 的旧窗口/程序，重新启动；
4. 刷新播放页。

### 一键转写报 HLS key / 视频源解析失败

1. 先 `Ctrl+R` 刷新播放页；
2. 确认扩展的 Cookie 权限已允许；
3. 仍失败时，把 `.ts` 下载/放进 `media`，用 **转写本机视频**。

### CPU 太慢

这个便携包默认是 **CPU + base**，为了能在任何电脑上直接跑，不包含 CUDA 运行库。
2 小时课可能需要几十分钟；有 NVIDIA 显卡的同学可以另行安装 CUDA 版服务，但那会显著增大包体。

### 转写有错别字

`base` 模型中文准确率一般；可在自己的电脑上使用更高模型，或把讲义/资料作为上下文辅助。此便携包不包含大模型。

### 杀毒软件拦截

便携 Python 可能被部分安全软件误报。把解压目录加入信任，或改用源码版。

## 四、隐私

- 本地服务只监听 `127.0.0.1`；
- 音频/视频/资料只在本机处理，不上传；
- HLS 的 Cookie/Key 只在本机扩展与服务之间使用，不写入服务器；
- 笔记、字幕、讲义、资料文字保存在浏览器本地存储；
- AI 只收到文字（笔记 / 字幕 / 资料页），**不会收到视频画面**；
- AI 请求只发往你自己配置的服务商。
- 扩展申请了 `management` 权限，只用于检测并清理同名的旧版/重复扩展，不会读取或改动其他扩展的数据。

## 五、卸载

1. `edge://extensions` 移除本扩展（如果有旧版条目也一起移除）；
2. 关闭 Edge 和 `启动服务.bat` 窗口；
3. 双击根目录的 `清理旧版残留.bat`，删除旧版文件夹；
4. 删除整个解压目录即可。

## 六、目录说明

```
manifest.json     Edge 扩展入口（根目录就是扩展）
src/、icons/       扩展代码与图标
runtime/          便携 Python 运行时
service/          本地转写服务 + base 模型缓存
media/            放本机音视频（可选）
启动服务.bat      双击启动本地服务
README.md         本说明
清理旧版残留.bat  删除旧版文件夹（升级后使用）
```

第三方组件：Python、faster-whisper、CTranslate2、PyAV、PyMuPDF、python-docx、python-pptx。
视频下载逻辑参考 PKU-Art（GPL-3.0），详见项目说明。
